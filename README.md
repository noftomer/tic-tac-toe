# איקס עיגול (Tic-Tac-Toe)

משחק איקס-עיגול בדפדפן, ללא תלויות חיצוניות (vanilla HTML/CSS/JS).

## תכונות
- **שני מצבי משחק**: שני שחקנים מקומיים, או נגד המחשב.
- **AI עם minimax** — המחשב משחק מושלם ולא ניתן לנצח אותו (לכל היותר תיקו).
- **מסך התחברות/הרשמה** עם שם משתמש וסיסמה (צד-לקוח, נשמר ב-`localStorage`).
- הדגשת הקו הזוכה, זיהוי תיקו, וכפתור "משחק חדש".

## הפעלה
פותחים את `tictactoe.html` בדפדפן. אין צורך בהתקנה או שרת.

## קבצים
- `tictactoe.html` — מבנה הדף.
- `tictactoe.css` — עיצוב.
- `tictactoe.js` — לוגיקת המשחק, ה-AI וההתחברות.

## ⚠️ הערת אבטחה
ההתחברות היא צד-לקוח בלבד: שם המשתמש והסיסמה נשמרים ב-`localStorage`
כטקסט גלוי ולא מוצפנים. מתאים לדמו/שימוש מקומי בלבד — לא למערכת אמיתית.
